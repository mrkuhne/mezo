# Warm-up before hard sets (RIR 0–2) — what the evidence and the field converge on

Three-way web sweep (2026-08-03, 3 parallel agents): evidence-based coach protocols (RP/Israetel,
Helms, Nippard, Ethier/BWS, Nuckols/SBS) · scientific literature (Iversen 2021, Ribeiro 2021,
Sousa 2020, Fradkin 2010/2006, PAPE trials) · app/program ramp schemes (RP app, Hevy, StrongLifts,
5/3/1, Liftosaur, Alpha Progression). Feeds the mezo warm-up feature (bd mezo-hbxq).

## The convergent protocol

**Reference weight is the WORKING weight** (not 1RM) — every app-computable scheme keys off it.

| Context | Warm-up | Ladder |
|---|---|---|
| **First compound of a muscle group** in the session | 2–3 sets | ~50% × 8 → ~70% × 4-5 → ~85-90% × 1-3 |
| Second+ exercise, same muscle (compound) | 0–1 set | one feeder ~60-70% × 3-5 |
| **Isolation / machine, muscle already warm** | 0 sets | first working-set reps double as warm-up |
| Very light working weight (&lt;~40 kg) | 0–1 set | steps below ~50% of working weight are useless — drop them |

- **Reps fall as load rises** (8 → 4-5 → 1-3); the heaviest step carries most of the benefit.
- **Warm-ups must never fatigue**: last step ~RIR 4-5, minimal volume. Evidence shows aggressive
  warm-ups gain reps on set 1 and lose them on sets 3-5 (net zero or worse).
- **Weight jumps ~20% of working weight per step**; round to 2.5 kg (down, not up); collapse steps
  that round to the same weight; floor at the empty bar (20 kg) for barbell lifts.
- **Rest**: 30-90 s between warm-up steps, ~2 min before the first working set (Ethier's numbers;
  only he quantifies it).
- **General cardio warm-up (5-10')**: weak, inconsistent evidence for lifting performance
  (Iversen 2021 "No Time to Lift" says skippable under time pressure) — keep optional.

## Science nuances worth remembering

- Controlled trials find **no measurable benefit** of 1-2 warm-up sets before *moderate-load
  (~10RM) machine sets to failure* in trained lifters (29-person crossover, Smith bench + leg
  press) — the case for warm-up is strongest for **heavy, low-rep, free-weight compounds**.
- More than 1-2 specific warm-up sets has **no experimental support** (Helms' up-to-6-set ladder
  is a strength-work convention, not an evidence requirement).
- PAPE ("potentiation" warm-ups near working weight) is real but **first-set-only and transient**
  — not worth engineering for multi-set hypertrophy work.
- Injury prevention from warm-up *sets* specifically: essentially no direct RCT evidence (distinct
  from multicomponent neuromuscular programs, which do help in field sports).
