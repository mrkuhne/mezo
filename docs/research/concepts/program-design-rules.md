# Hypertrophy program-design rules — the encodable expert consensus

Three-agent web sweep (2026-08-03) of RP Strength/Israetel per-muscle guides, Helms' Muscle &
Strength Pyramid (via rippedbody.com applied guide + book mirrors), Nippard program templates
(via reviews/mirrors), and Built With Science articles. The rule set mezo's guided meso-building
should encode. Feeds bd mezo-oyhy (guided building epic).

## Session-structure rules (converged)

| Rule | Value | Source spread |
|---|---|---|
| Exercises per muscle per session | **1–3** (hamstrings/traps: 1) | RP explicit per-muscle; Nippard/Ethier templates comply |
| Sets per exercise | **2–4** compound, **2–3** isolation; 2 is a legit start | RP ("start low"), Nippard, Ethier |
| Max productive sets per muscle per session | **~8–12** (RP), **~11 fractional** (Helms) | matches the video's 10-11 cap |
| Exercises per workout (templates) | **5–9** | Nippard 6, Ethier 6+1-2 |
| Order | compounds/heavy first, isolations after; explosive/plyo quality work first | Ethier (CNS rationale), RP (heavy→light across week) |
| Session length | ~45–90 min; 20 min too short, 3 h counterproductive | Nippard 60-90, RP qualitative |

## Weekly-structure rules

| Rule | Value |
|---|---|
| Frequency per muscle | **≥2×/week** universally; small muscles (delts/arms/calves) tolerate 3–6× |
| Distinct exercises per muscle per WEEK | **2–5** (RP; hams/traps 2–3) — few exercises done well beats variety |
| Same exercise 2×/week | encouraged; rotate only on stalled progression (RP swap criteria) |
| Rep-zone distribution (RP) | **~25% heavy (5-10) · ~50% moderate (10-20) · ~25% light (20-30)** per muscle per week; side/rear delts skew light, hip-hinge skews heavy |
| Rep assignment (Ethier) | compounds 3–8 rep @ 2-4' rest; isolations 10–20 rep @ 60-90" rest |
| Balance | push:pull sets ≈ **1:1**; ham:quad ≈ **0.6–0.8:1** (structural-balance literature, NOT the three experts); Helms implicit pull-bias (2 mandatory row variants vs 1 press) |

## Weekly volume targets per muscle (working sets)

The experts disagree on absolute numbers — an app should show BANDS, not one number:

| Source | Minimum effective | Practical optimum | Ceiling |
|---|---|---|---|
| RP landmarks (intermediate) | MEV: 4-10 (muscle-specific) | MAV: 6–24 (muscle-specific) | MRV: 8–30 |
| Helms | ~4 | **10–20** | ~30 (specialization) |
| Ethier/BWS | 3 (maintain) | **4–7** "min-effort optimum"; >10 for max gains | — |
| Ethier video (set-volume-landmarks) | — | failure style 5–12 · volume style 12–20 | 12 / 20 |

Key RP MEV/MAV/MRV rows (full table in the sweep report): chest 4-6/6-16/16-24 · back ~10/~20/~25 ·
quad 4-6/6-14/14-18 · ham 2-4/2-8/8-14 · glute 6-8/8-24/24-30 · side delt 6-8/8-24/24-30 ·
biceps 8-10/14-20/20-26 · triceps 4-6/6-16/16-20 · calf 4-6/6-16/16-24. RP itself calls these
"starting points, not gospel" — re-verify near implementation.

## The counting controversy (must be a conscious app decision)

Indirect/synergist volume: **Helms counts 0.5** per synergist set (row = 1.0 back + 0.5 biceps);
**Ethier counts 1.0** (bench = 1 chest + 1 triceps); RP counts direct only. mezo currently counts
direct only — adding fractional counting changes every budget number; whichever is chosen must be
explained in the UI.
