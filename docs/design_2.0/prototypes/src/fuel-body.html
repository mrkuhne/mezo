A Fuel hub felépítése

  • Keret-hero — a régi KeretHero minden ténye: hátralévő kcal (őszinte mínusszal túllépésnél), eddig / cél sor, ablak-számláló, arányos nap-sáv a kész ablakok szegmenseivel + arany MOST-jelölő, energia-chipek (Alap / Mozgás / Cél — statikus energiánál az egész sor eltűnik), és az 5 gyűrű: Fehérje · Szénhidrát · Zsír · Rost · Víz. A víz-gyűrű gomb — logoló sheetet nyit.
  • Ablak-swimlane — minden beütemezett étkezési ablak (amire az AI is ajánl) saját csempét kap egy vízszintesen görgethető sávban, saját clay étel-ikonnal (tojás / tál / alma / fazék). Minden csempén kcal mini-csempe + három mini makró-gyűrű (P korall · C borostyán · F levendula — a kitöltés azt mutatja, ez az étkezés mennyit tesz a napi célba). Kész: zsálya wash, KÉSZ ✓, az étel neve és az AI-pont chip (a frissen logolt ✨ folyamatban). MOST: korall keret + Logold CTA, a terv-étellel. Kimaradt: szaggatott borostyán keret, „még pótolható" + Pótold — sosem büntető. Jövőbeli: terv-javaslat + ghost Logold. A sáv a MOST-csempére gördül be, a sor végén az „ablakon kívüli" logolás-csempe (＋ Logolás / ✨ AI). A fejlécben az AI-átlag — csak pontozott étkezésekből.
  • Terv — heti stat-sor (kcal-átlag, protein-napok, stack-adherence, gym+sport), 24 órás heti ritmus-rács a gym/röpi sávokkal és a konyhazárás + koffein-cutoff jelölőkkel (a beállításokból számolva — a mai oldal hardcode-ját javítja), gyógyszer-ciklus csík. Az üres szekciók (minták, supplement-térkép) nem foglalnak helyet.
  • Stack — zóna-kártyák idővel és horgony-jegyzettel (edzés −45p, lefekvés −30p…), pipálható sorok (a hero és a csempe élőben számol), 📌 kézi rögzítés, étkezés-egyeztetés (✓ / ⚠ borostyán tanáccsal), „Miért így" átláthatóság.
  • Receptek — típus-szűrő élő darabszámmal (a Snack új fület kapott), kártya: kép-sáv slot-chippel és szerep-címkével, név, makrók /adag, hozzávaló · perc · NOVA-pont (1 zsálya / 2–3 borostyán / 4 terrakotta), fit-jelvény vagy ✨ amíg pontozatlan.
  • Kamra — kereső + típus-váltó darabszámmal (a Gyógyszer is fület kapott), típus-csoportos lista (étel: makrók + NOVA + kcal; supp: protokoll-sor + dózis).
  • Gyógyszer — készítmény-kártya ciklus-csíkkal (csúcs = terrakotta, sosem piros), fázis-jegyzet, beadás-lista jegyzettel. Új ikon: i-injekcio.
  • Napló — design-kiegészítés a „sehol egy trend" gapre: kcal-átlag, AI-átlag és protein-napok 4 hetes oszlopai a heti API teljes sorából.

A hub a Mai oldal lelke: egy pillantás — mennyi fér még, mi a következő ablak, mi van kipipálva. A mélyebb körök (log-sheet teljes köre, AI-napló, szerkesztők) oldalanként készülnek tovább.
