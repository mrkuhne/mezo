Mi került az aloldalakra

  • Heti — stat-sor (szett/RPE/medál), napi lista medál-garnírunggal, és az izom-zóna kártya (régi Gym): szaggatott cél-zóna sáv + teli valóság-sáv, a Láb zóna alatt terrakottában.
  • Mesociklus — volumen-ív fázis-címkékkel (MOST/csúcs/deload), e1RM-trend sparkline, fázis-kártya, futam-történet riport-gombokkal, sablonok.
  • Sport — heti stat-sor, slotok (ma kiemelve, Logold), cross-load kártya.
  • Futás — blokk-ív égszínben, legutóbbi futás kör-idő oszlopokkal (1:32 átlag), következő sessionök.
  • Gyakorlatok — kereső + izomcsoport-chipek, rekord-sorok saját sparkline-nal és clay medállal.
  • Medálok — dátum-csoportos vitrin, REKORD/CÉL típus-címkék, „mit múlt felül" sorok.

Minden oldal ugyanabból épül: színes hero (spot + nagy szám) → stat-sor → adat-grafika → lista-kártya → csendes elv-mondat alul. Semmi piros, semmi büntetés.
