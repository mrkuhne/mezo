# 0041 — Boop editorial typography and original line icons

- **Status:** Accepted for prototype
- **Date:** 2026-09-09
- **Driver:** mezo-88jw.6

## Context

After trying the Boop iteration, Daniel rejected both the added facial features and the Clay icon set. He preferred the earlier editorial styling and requested an original icon family.

## Decision

Restore the original Avatar Lab definition, with only its two eyes. Remove the additional face overlay and decorative heart. Replace the Clay sprite with original monochrome SVG paths using a 24-unit grid, thin strokes and rounded ends. Restore Newsreader headings and italic accents over warm paper surfaces; retain softer navigation corners and sans interface labels.

## Consequences

The Boop name, navigation and continuous chat remain. Earlier comparison studies stay unchanged. The standalone prototype no longer depends on the Clay icon sprite. The new icon family is editable in source and inherits domain color. No production migration is implied. This supersedes the typography, icon and facial styling in ADR 0040. See [the current guide](../design_3.0/presence-navigation.md).
