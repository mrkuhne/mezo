# ADR 0023 — Fuel Mai is a river of window-islands: the eating window as unit, an always-visible Keret-öv

- **Status:** accepted (2026-08-08)
- **Driving bd:** `mezo-jgh9`
- **Spec:** [`docs/superpowers/specs/2026-08-08-fuel-window-river-design.md`](../superpowers/specs/2026-08-08-fuel-window-river-design.md) (+ the interactive mockups under `specs/assets/`)
- **Precedent:** [ADR 0022](0022-today-three-islands.md) — Today's sky-of-islands language (`shared/ui/Island`, capsule↔big morph, `MOST` ring, L0/L1 layering) is reused verbatim; this ADR is the record of Fuel becoming its **second consumer**, which is what promotes the shell out of `features/today/`.

## Context

Fuel's guided Mai redesign (`mezo-rrtj`, 2026-07-28) had already replaced the original flat `SlotCard`/`KcalGauge` timeline with a hero (`NowWindowCard`) + a day-status card (`DayBudgetCard`) + napszak zone cards (`DayZoneCard`/`ZoneSlotRow`) + a missed-window strip (`MissedStrip`) — a real improvement, but still a **stack of co-equal cards** under a header row, the same shape ADR 0022 diagnosed and fixed on Today. Once Today's three-islands sky shipped, the user asked for the same "sky, layers, alive surface" treatment on Fuel — but built on Fuel's **own unit**, not a daypart: the **eating window** (a `buildDayPlan` slot). The second ask was that the day's kcal/macro budget — what the old `DayBudgetCard` printed once, mid-stack — be reachable **any time, one glance**, not buried behind a scroll position.

## Decision

`/fuel` (Mai) becomes a **non-scrolling sky** between `AppHero` and the tab bar, mirroring Today's `IslandSky` layout hook exactly (`.screen-content:has(.sky-islands)`):

1. **One island per eating window** — `logic/windowIslands.ts`'s pure `buildWindowRiver()` turns `buildDayPlan`'s slots into a chronological river of `WindowIslandVM`s (`done|now|missed|future`), each carrying its own capsule essence/count, hero subtitle, and 0–2 DS delta-fact cells (protein-jump, day-score). The existing `pickHeroWindow` projection (unchanged) still decides which window is `now` — no second state machine.
2. **`components/WindowIsland.tsx`** renders one window's L0 (hero + meal-chip + facts + CTA row) and L1 (ablak étkezése / csere a tervben / AI naplózás / stack-adagok kötve ehhez az ablakhoz), riding the shared `Island` shell exactly the way Today's `IslandMorning`/`IslandDay`/`IslandEvening` do.
3. **`components/KeretBelt.tsx`** is the always-visible daily-budget belt: a thin (54px) `Island` in its `belt` variant sitting right after the NOW-island (or after the last **done** island when there is no `now` window — never blindly the chronologically last island, which may be `missed`). Tapping it promotes it to the big island, showing the eaten/remaining bar, the energy breakdown (alapanyagcsere → mozgás → cél-deficit → mai keret), full macro bars, the water row, and a "＋ Log bármikor" ad-hoc-log row.
4. **`?w=` is the single source of truth** for which island is big — an index/`'keret'` key, no param → the river's `defaultKey` (the `now` window, or `'keret'` when the day has none) — replicating `TodayPage`'s `?dp=` rules verbatim: `replace: true`, deleted from the URL on default, any null/empty/unknown value falls back silently.
5. **The Island shell is promoted to `shared/ui/Island.tsx`** on the project's 2nd-consumer rule (ADR 0018/`_platform-design-system.md` §1a): Fuel's window-river is that second consumer. The shell drops every Today-specific name — `data-face` → `data-tone` (`'reggel'|'nap'|'este'|'fuel'|'keret'`), and gains a `belt` boolean (fixed-height, no float) + a `beltContent?: ReactNode` override so `KeretBelt`'s richer collapsed row (remaining-kcal number + three macro mini-bars) can replace the generic emoji/title/essence/count capsule without the shell learning anything domain-shaped. `TodayPage.tsx` becomes a plain caller, unaffected in behavior (goldens pin this).
6. **A new `--gradient-sage`/`--shadow-sage` token pair** (parallel to `--gradient-cta`) gives Fuel's own CTAs a domain-accent look (`.isl-cta.cta-sage`) without touching the coral CTA gradient Today/the rest of the app uses.

## Consequences

- **Retired components (+ their tests), all zero-consumer after the recomposition:** `NowWindowCard`, `DayZoneCard`, `DayBudgetCard`, `MissedStrip`, and — as a direct, mechanical consequence of `DayZoneCard`'s retirement (it was `ZoneSlotRow`'s only host) — `ZoneSlotRow` itself. `pickHeroWindow`'s own logic survives (it now feeds `buildWindowRiver`); `logic/dayZones.ts` (`buildDayZones`/`DayZone`/`slotRole`) survives too — `compileTemplate`/`validateSlotPlan`/`heroWindow`/`buildDayPlan`/`fuelConfig` still depend on it, only its two presentational consumers are gone.
- **Retired CSS families:** `.nowcard*`, `.retamicro*`, `.missedstrip*`, `.daybudget`/`.dayseg`/`.brk`/`.ebchip*` and the base `.macror`/`.mac*` bars (the older Napiv-S6-era family `DayBudgetCard` had inherited), the `ZoneSlotRow`/`DayZoneCard`-only nested rules inside the shared `.zcard`/`.zrow` family (`donez`/`openz` zone-state tints, `.caps`/`.burn` stack-pip dots, `.zf`/`.zv`/`.zacts`+`.log`/`.ai`, `.missedrow`/`.act`(`.sport`)/`.anchor`, `.mm` macro dots), the standalone `.misstag`, and `.coachline`/`.cskel` — plus the `np-hero-pulse`/`np-seg-grow`/`np-sk-slide` keyframes those rules alone animated. **`.zcard`/`.zh`/`.zn`/`.zk`/`.zrow`/`.zt`/`.a`/`.b` all survive** — `FuelStackPage`'s `StackZoneCard` rides the exact same base family, verified by grep before any deletion.
- **A real feature went dark, deliberately not deleted:** the meal-coach tagline/AI-score-chip surface (`useMealCoach`, `MealScoreChip`, `MealScoreSheet`, `getScoredMeal`) rode **only** on the retired `ZoneSlotRow` — `MealScoreSheet` had no other opening path anywhere in the app, on main or on this branch. `WindowIsland` has no per-window score slot today (see honest-null facts below), so this P7-real, backend-scored, LLM-coached surface is currently **unreachable from any UI**, not deleted — `MealScoreChip.tsx`/`MealScoreSheet.tsx`/`ScoreHero.tsx`/`useMealCoach` and their `.aiscore*` CSS all still exist and pass their own tests. This is flagged as a follow-up (re-wire into a future `WindowIsland` score fact, or retire formally) rather than resolved here, since deleting a real backend-integrated feature is a bigger call than a page recomposition.
- **Honest-null facts, not a broken feature:** `FuelSlot` carries no per-window `mezoFit` score, and `windowIslands.ts`'s input has no meals array to look one up by id — so `meal.fit` and `facts.dayScore` are **permanently null** until a future slice threads a score lookup through `buildWindowRiver`'s input. The UI renders those cells/badges conditionally (no `—` fabrication, no fake number) — the same honest-cell rule ADR 0022's `islandFacts.ts` established for Today.
- **Accepted trades:**
  - **`onStackDose` deep-links to `/fuel/stack`** instead of ticking a dose in place — the L1 stack-adagok row's data comes from a `MealMatchVerdict` (`matchMealsToStack`), which carries no `pantryItemId`/occurrence id, so there is no honest per-dose "check" action reachable from this data shape; `useStackActions().logIntake` needs a real stack occurrence, which only the Stack page's own `useStackDay` composition has.
  - **The protocol-meta/Replan row is gone from Mai** — it now lives only on the Stack page, which is its natural home (the page that actually owns the protocol version + replan scenarios).
  - **No `FuelMaiSkeleton`** — the page never had a loading branch to begin with (real-mode composed hooks all seed synchronously via `initialData`/ghost defaults), so none was added.
  - **The kitchen-close/caffeine-cutoff reference row and the `FuelSettingsSheet` entry point** (`＋ szerkeszt ›`) both folded into `KeretBelt`'s note footer — `FuelSettingsSheet` has exactly one trigger in the app now, `KeretBelt`'s `onEditSettings`.
- **Follow-ups filed:** thread a per-window/meal score lookup into `buildWindowRiver`'s input so `facts.dayScore`/`meal.fit` can light up; decide `MealScoreChip`/`MealScoreSheet`'s fate (re-wire vs. formal retirement) once that lands; visual goldens for the new sky states (NOW-nagy / keret-nagy / L1-nyitva / missed) regenerate via the usual darwin+linux workflow.
