# 0047 — Karakter as a social reading and correction surface

- **Status:** Accepted
- **Date:** 2026-09-20
- **Driver:** mezo-njcgs

## Context

The owner could not follow the equally weighted hub tiles and technical council hierarchy. They approved the third interactive prototype and requested implementation through deployment. Reading the team's reasoning should feel like a social feed, and personal corrections must influence actual knowledge rather than disappear into feedback counters.

## Decision

Open Karakter on Üzenőfal with Rólad and Csapat as primary destinations. Keep technical sources and runs under Hogyan működik?. Use the existing Clay assets, Mozaik washes and shared GlassBox for evidence. Display only stored expert reactions; a missing debate remains absent.

Allow replies to server-owned, stable observation/claim/conference-change sources. Save the original context and self-report before an asynchronous targeted Mezo evaluation. The original expert domain informs the evaluation; it does not manufacture participation from other personas. Persist the reason and outcome, update the existing claim lifecycle/portrait only when appropriate, and make self-report available to shared memory consumers. Retry the same saved reply with an owned processing lease rather than duplicating evidence. Source logs and plans are never changed by this flow.

## Consequences

A user can see what was saved and what changed, and recover failed processing without losing their words. This amends the original read-only team boundary: the user can answer the team's work, while Mezo returns the evaluated response. Persistent reply state, source ownership and concurrent claim updates become explicit contracts. Model inference is still distinct from personal testimony.

## Alternatives considered

Waiting for the weekly council would leave the immediate interaction unresolved. A frontend-only comment stream would promise knowledge without providing it. Fictional reaction counts or automatic agreement would misrepresent what the team actually evaluated.
