# 0040 — Boop companion identity in the UX prototype

- **Status:** Accepted for prototype; production migration deferred
- **Date:** 2026-09-08
- **Driver:** mezo-88jw.5

## Context

Daniel selected the presence-based navigation but found its editorial styling unsuitable for an intelligent AI companion. He named both the app and character Boop and requested a friendly pet-like quality while retaining the existing Clay icon vocabulary.

## Decision

The isolated presence prototype uses Boop branding, modern sans typography, warm luminous surfaces, the existing Clay icon sprite and an expressive Avatar Lab character. Pet-like feedback is optional and immediate: touching Boop elicits a brief happy response. Domain navigation and continuous contextual conversation remain the organizing structure.

## Consequences

The visual identity can be evaluated across the existing domain summaries without migrating the production app. Older comparison prototypes keep their identity. Added brows, cheeks and smile are an SVG overlay rather than a fully rigged face; production animation would need to align them with head motion. No pet-care obligations or additional gamification are introduced. Implementation and interaction details live in [the study guide](../design_3.0/presence-navigation.md).
