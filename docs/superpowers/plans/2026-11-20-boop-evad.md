# Boop B6 Évad — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Terv place into **Évad** — one N-week season that owns the goal, the training block and the weekly
gym + sport slots, derives food targets, sleep need and weight course, previews every change live, and carries the
weekly menu, shopping list and experiments.

**Architecture:** New backend feature `season` (aggregate owning its `goal` 1:1, reusing `goal_plan_link`, writing
the existing train slots and `sleep_goal` on accept) behind a no-persist draft preview built on the goal engine's
calculator. iOS replaces `TervView` with an `NKAreaPage` + `NKAreaTabs` page over a hand-written lenient client
(`RawJSONClient`, the Pénz pattern) cached in `ServerCache`. Built and shipped in four slices S1 → S4.

**Tech Stack:** Spring Boot 3 / Java 21, Liquibase, OpenAPI-first (`api/feature/season/season.yml`), JUnit + Testcontainers;
SwiftUI iOS 26, BoopKit (BoopCore, BoopDesign/Napkelte), Swift Testing with `StubTransport`.

**Status:** owner-approved 2026-11-20 (spec, spike and this plan). **Spec:** `docs/superpowers/specs/2026-11-20-boop-evad-design.md` (read §5 and §5.12 before any task).
**Spike (look + copy reference, throwaway):** branch `feat/b6-evad`, `ios/Boop/EvadDemo/EvadDemo.swift`, screenshots
`docs/superpowers/specs/assets/evad/01–13`. Copy strings are taken from the spike verbatim unless a task says otherwise.
