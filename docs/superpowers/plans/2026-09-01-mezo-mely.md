# F7.5 Mezo mély kör — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline).
> Spec: docs/superpowers/specs/2026-09-01-mezo-mely-kor.md

**Goal:** Conversation rename/delete, error-bubble retry, and the Memoir archive (timeline +
chapter page) — contract + backend + FE, goldens, docs.

**Architecture:** Two small contract additions (companion PATCH/DELETE conversation, proactive
memoir archive list) ride the existing service idioms (`getOwned` 404, soft delete already wired,
repo finder + mapper). FE: one new actions sheet + retry state in `useChatActions`; memoir gets a
`useMemoirArchive` dual-query and two new Mozaik pages walking one shared query.

**Tech Stack:** Spring Boot 4 + openapi-generator; React 19 + TanStack Query; vitest (both
modes); Playwright visual.

## Global Constraints

- 1:1 prototype fidelity (mezo-chat.html F7.5 additions; mezo-memoar.html) — colors/copy verbatim.
- ADR 0010: delete confirm is warm, never punishing; ADR 0032 IA; Mozaik 2.0 (ADR 0033).
- Both vitest modes green; `npx tsc -b`; `pnpm build`; lint-docs --errors-only; codemap --check.
- New endpoints 404 honestly under switch-off; ownership 404 via getOwned idiom.
- Commit per slice, conventional subjects with (mezo-d20.8.5.1), Fable-5 footer.
