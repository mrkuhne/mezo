# Kihagyás S1 — skip a gym / sport / run occurrence with a reason — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One tap "Kihagyom / Kihagytam" on a planned gym day, sport occurrence or prescribed run (today, the rest of the week, the last 7 days), an optional reason sheet, persistent undo, a weekly free pass, and one central "is this skipped / excused?" read that every missed/streak/adherence consumer honours.

**Architecture:** A new per-date overlay table `planned_skip` (soft-delete undo, partial unique index) in `feature/train`. `PlannedSkipService` is the central read (union with the legacy advice table `sport_slot_skip`); a pure `PlannedSkipPolicy` decides serious/soft, the free pass and "excused" at read time, so undo never needs recomputation. The FE gets a dual-mode hook, a glass reason sheet, a muted "Kihagyva" block on the Edzés cards, and one `isSkipped()` helper that the planning readers (Nap timeline, orb, Fuel, notifications) use to hide skipped occurrences.

**Tech Stack:** Spring Boot 3 / JPA / Liquibase / PostgreSQL; OpenAPI fragments → generated `api.gen.ts` + Java DTOs; React 18 + TanStack Query + Vitest; Titanium SVG sprite.

**Spec:** `docs/superpowers/specs/2026-09-28-kihagyas-kimelo-mod-design.md` §8 (S1 delta).
**Approved prototype:** `docs/design_2.0/prototypes/elo/edzes.html` (`#mai`, `#mai/sze`, `#ikonok`), Artifact https://claude.ai/artifact/DdTK5jJ6XTBuqnPSC3fpcC.

## Global Constraints

- Reason enum (contract between UI, rules, and later S4 AI): `ILLNESS, STOMACH, INJURY, TRAVEL, TIRED, NO_TIME, NO_MOOD, OTHER, NONE`.
- Serious = `ILLNESS, STOMACH, INJURY, TRAVEL` → never counts as missed. Soft = `TIRED, NO_TIME, NO_MOOD, OTHER, NONE`.
- Free pass: per ISO week (Mon–Sun, Europe/Budapest) **of the skip's date**, the first soft `USER` skip (gym + sport + run together) ordered by `created_at`, then `id`, is excused. Computed at read time; never stored.
- Advice skips (`sport_slot_skip`) read as `SPORT / NONE / source=ADVICE`, always excused.
- Excused = serious OR advice OR free-pass. Excused skips leave the planned count; non-excused skips count like today's plain miss.
- Skip window: `today − 7 ≤ date ≤ Sunday of the current ISO week` (Europe/Budapest). Outside → 400 `TRAIN_SKIP_DATE_OUT_OF_WINDOW`.
- Weekday numbering for SPORT = 0=Hét..6=Vas (`date.getDayOfWeek().getValue() - 1`), NOT ISO.
- A skip is **never** a `workout_session` row.
- `reason_text` is stored only for `OTHER`, trimmed, max 500 chars.
- Copy: Hungarian, adherence-neutral; forbidden words in any skip string: `elrontott|túlléptél|hiba|rossz|bukta|kudarc`.
- Icons: Titanium sprite only (`t-skip, t-ill, t-digestion, t-pain, t-travel, t-rested, t-clock, t-motivation, t-other, t-mic, t-shield, t-repeat`), never emoji.
- ArchUnit: `train` never imports `companion`/`proactive`; layer subpackages (`controller/service/entity/repository`).
- `VITE_USE_MOCK` unset = mock; the real-mode gate needs `VITE_USE_MOCK=false` explicitly. FE tests need `CI=true`.

```sql
-- Kihagyás S1 (mezo-q4xt2.1, spec 2026-09-28 §8): one user-declared skip of a planned occurrence —
-- a gym day, a recurring sport slot occurrence or a prescribed run — with an optional reason.
-- A read-time overlay (the readiness_choice / workout_day_adjustment idiom): never a template edit,
-- never a workout_session row. Undo is a soft delete. Whether a skip counts as missed (serious
-- reason / weekly free pass) is computed at read time by PlannedSkipPolicy, never stored.
-- SPORT keys on the slot IDENTITY (day_of_week 0=Hét..6=Vas + time), like sport_slot_skip, because
-- sport_schedule_slot rows are re-inserted on every save. RUN keys on the block session key.
create table planned_skip (
    id              uuid         not null default gen_random_uuid(),
    created_by      uuid         not null,
    is_deleted      boolean      not null default false,
    created_at      timestamptz  not null default now(),
    updated_at      timestamptz  not null default now(),
    date            date         not null,
    kind            varchar(8)   not null,
    day_of_week     smallint,
    time            varchar(5),
    session_key     varchar(64),
    reason_category varchar(16)  not null default 'NONE',
    reason_text     varchar(500),
    constraint pk_planned_skip_id primary key (id),
    constraint fk_planned_skip_created_by_app_user_id
        foreign key (created_by) references app_user (id) on delete cascade,
    constraint ck_planned_skip_kind check (kind in ('GYM', 'SPORT', 'RUN')),
    constraint ck_planned_skip_reason check (reason_category in
        ('ILLNESS', 'STOMACH', 'INJURY', 'TRAVEL', 'TIRED', 'NO_TIME', 'NO_MOOD', 'OTHER', 'NONE')),
    constraint ck_planned_skip_day_of_week check (day_of_week is null or day_of_week between 0 and 6),
    constraint ck_planned_skip_target check (
        (kind = 'GYM'   and day_of_week is null and time is null and session_key is null) or
        (kind = 'SPORT' and day_of_week is not null and time is not null and session_key is null) or
        (kind = 'RUN'   and day_of_week is null and time is null and session_key is not null))
);
create unique index uq_planned_skip_target
    on planned_skip (created_by, kind, date, coalesce(day_of_week, -1), coalesce(time, ''), coalesce(session_key, ''))
    where is_deleted = false;
create index ix_planned_skip_user_date on planned_skip (created_by, date) where is_deleted = false;
```

```java
public static List<Verdict> judge(List<Row> rows) {
    Map<Long, UUID> passByWeek = new HashMap<>();
    rows.stream()
        .filter(r -> r.source() == Source.USER && !isSerious(r.reason()))
        .sorted(Comparator.comparing(Row::createdAt).thenComparing(Row::id))
        .forEach(r -> passByWeek.putIfAbsent(isoWeekKey(r.date()), r.id()));
    return rows.stream().map(r -> {
        boolean serious = isSerious(r.reason());
        boolean pass = r.source() == Source.USER && !serious && r.id().equals(passByWeek.get(isoWeekKey(r.date())));
        return new Verdict(r, serious, pass, serious || pass || r.source() == Source.ADVICE);
    }).toList();
}
```

```java
private static final ZoneId TZ = ZoneId.of("Europe/Budapest");

@Transactional
public PlannedSkipResponse upsert(UUID user, PlannedSkipRequest req) {
    LocalDate today = LocalDate.now(TZ);
    LocalDate date = req.getDate();
    LocalDate sunday = today.with(TemporalAdjusters.nextOrSame(DayOfWeek.SUNDAY));
    if (date.isBefore(today.minusDays(7)) || date.isAfter(sunday)) throw bad("TRAIN_SKIP_DATE_OUT_OF_WINDOW");
    Kind kind = Kind.valueOf(req.getKind().getValue());
    validateTarget(kind, date, req);                       // throws bad("TRAIN_SKIP_TARGET_INVALID")
    lock.lock(user);
    PlannedSkipEntity row = repository.findByCreatedByAndDateBetweenAndDeletedFalse(user, date, date).stream()

}
```
