# Boop iOS v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Boop v1 — the owner's morning as a native SwiftUI iPhone app in the Lágy look, against the existing backend — in four slices; this document details **slice S1** (the app frame: project, Lágy kit, sign-in, onboarding, five-domain shell, weekly install) and maps S2–S4, each of which gets its own detailed plan when it starts.

**Architecture:** An Xcode app target `Boop` under `ios/` depends on one local Swift package `ios/BoopKit` with three library targets: `BoopAPI` (client generated from `api/openapi.yml` by swift-openapi-generator, filtered to the operations Boop uses), `BoopCore` (token storage, session state, API wiring), `BoopDesign` (the Lágy kit ported from the approved spike, with fonts, glyphs and photos as package resources). Screens live in the app target, one folder per area.

**Tech Stack:** Swift 6, SwiftUI, Observation, Swift Concurrency, apple/swift-openapi-generator + swift-openapi-runtime + swift-openapi-urlsession, Security (Keychain), Swift Testing, Xcode 27.2 (`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`), iOS Simulator "iPhone 17 Pro Max".

**Spec:** [`docs/superpowers/specs/2026-11-09-boop-ios-v1-design.md`](../specs/2026-11-09-boop-ios-v1-design.md) (read §0 Lágy pivot and §4 first). **Approved look:** [`docs/design_2.0/prototypes/boop-ios-spike/`](../../design_2.0/prototypes/boop-ios-spike/README.md) — the `Lagy*.swift` files are the build target; copy, don't reinvent.

## Global Constraints

- Deployment target **iOS 26.0**; portrait only; Hungarian only.
- Bundle id **`io.mrkuhne.boop`**, display name **Boop**, App Group `group.io.mrkuhne.boop` reserved (not yet used). Never rename the bundle id (free team: ≤ 10 App IDs per 7 days).
- Signing: free Personal Team; the team id is **never committed** (pass `DEVELOPMENT_TEAM` at build time). No push, iCloud, Associated Domains or Sign in with Apple capabilities.
- API base URL **`https://46.225.112.172.sslip.io/api`**; JWT lasts 30 days, **no refresh token** — a 401 sends the user to sign-in.
- Every non-2xx body is a `SystemMessageList` (array of `{code, type, level?, message?, fieldName?, params?}`).
- Lágy canon (`.claude/skills/lagy/IRANY.md` on branch `claude/mai-napom-custom-graphics-eedeb2`): tokens exactly as in the spike's `Lagy.swift`; Outfit (display, numbers) + Manrope (body); Lágy glyphs, **no emoji, no SF Symbols** except system chevrons/arrows; photo head on every page; one deep-green card per page; Boop card at the end.
- The companion is **Boop**, never "Mezo", in every string.
- Copy: Hungarian business-plain, **"kalória", never kcal**, no grey helper lines, text ≥ 12 pt, taps ≥ 40 pt (primary ≥ 44 pt), decimals with a comma (`82,4`).
- No backend changes in S1. Later slices add **new** Boop endpoints; the web app's shared AI paths (morning prompt, meal coach) are never altered in a way that changes web output.
- The owner's real data never goes into code, fixtures, docs or screenshots committed to the repo.
- `ci.yml` does not build `ios/`; iOS gates run locally (Task S1-8).

## Review Focus

1. **Expired or revoked token at launch** (day 31, or a server-side reset) → the sign-in screen, never a blank screen, spinner loop or crash. Test in Task S1-3.
2. **No network / server down at launch with a stored token** → keep the token, show the Lágy error card with "Újra", do **not** sign out. Test in Task S1-3.
3. **Onboarding interrupted** (app killed after the profile was saved) → reopening resumes at the weight step, not at profile again and not in the shell. Test in Task S1-5.
4. **Weight near midnight / Hungarian decimals** → the logged `date` is the device's local calendar day (23:30 local is still today), the posted `weightKg` is a plain number (82.4) while the screen shows `82,4`. Tests in Task S1-5.
5. **Register errors** → invite code used/expired and e-mail already taken each show their own Hungarian sentence under the right field, and the form keeps what was typed. Test in Task S1-3 (mapping) and Task S1-4 (form state).
